Integrações e mensagens automáticas

Como o site conversa com o seu sistema atual e com o WhatsApp. Os endpoints abaixo são o contrato sugerido para a implementação.

Estoque: sincronização

O sistema atual envia cada mudança por webhook. O site nunca vende o que já saiu do estoque.

POST /api/webhooks/estoque
{
  "evento": "unidade.atualizada",
  "sku": "UN-4471",
  "tipo": "seminovo",
  "status": "disponivel | reservado | vendido",
  "preco": 2390.00,
  "grade": "A+",
  "bateria": 100,
  "garantia_dias": 180
}

Ordem de serviço: status e WhatsApp

Cada mudança de etapa dispara uma mensagem pela API oficial do WhatsApp (ou Z-API).

POST /api/webhooks/os
{
  "os": "48213",
  "etapa": "aguardando_aprovacao",
  "cliente": { "nome": "Marcos", "whatsapp": "5511900000000" },
  "complemento": { "descricao": "Conector oxidado", "valor": 120.00 }
}
→ envia template  os_status_{etapa}
